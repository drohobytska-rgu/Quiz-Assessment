All team members should use the same variable names where the same information is being used.

## Player / Game Variables

- `playerName` // stores the player's name
- `totalScore` // stores the player's total score across the whole quiz
- `roundScore` // stores the score for the current category/round
- `correctAnswers` // number of correct answers
- `wrongAnswers` // number of incorrect answers
- `currentQuestion` // current question number
- `gameRunning` // shows whether the quiz is still running
- `playAgain` // stores whether the player wants to restart the quiz

## Question Variables

Every member should use the same names for question information:

- `questionNumber`
- `questionText`
- `answerOptions`
- `correctAnswer`
- `questionPoints`
- `categoryName`

## Functions

Every member should use the same names for functions:

- 'askTimedQuestion()' // This function is for setting the timer rather than having to write out the full code every single time.

## Input Variables

- `playerAnswer` // answer entered by the player
- `menuChoice` // main menu selection
- `categoryChoice` // selected quiz category

## Question Collections

Use consistent names for each member's question collection:

- `generalKnowledgeQuestions`
- `technologyQuestions`
- `cybersecurityQuestions`
- `scienceQuestions`
- `geographyQuestions`

## Team Rule

If two parts of the program represent the same information, use the same variable name.

For example:

✅ `totalScore` everywhere  
❌ `score`, `total`, `finalScore`, `pointsTotal` in different files
